LANDING PAGE HERO CAROUSEL — MANUAL LANGUAGE FILES

Edit these files to control the landing-page hero independently for each language:
- js/hero-carousel/en.js — English
- js/hero-carousel/si.js — Sinhala
- js/hero-carousel/ta.js — Tamil

Each file contains:
- fixedHero: eyebrow, title, description, buttons, and the three feature points
- slides: tag, titleLine1, titleLine2, description, button labels, place, and region for each carousel slide
- rotatingMessages: the rotating fixed headline and description messages

The language buttons only select the matching file. There is no automatic translation.
Keep the same object keys and number/order of slides when editing. Save the file and refresh the site.
The other website sections continue using js/content/en.js, si.js, and ta.js.
